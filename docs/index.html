Start Here

PineJS is a lightweight, fine-grained declarative micro-framework for building modern reactive web applications directly in your HTML markup.

🌲 Signals + Alpine Ergonomics: Powered by true Fine-Grained Signals with atomic DOM bindings, sub-millisecond execution latency, and < 8 kB footprint.

Quick Example

HTML
<script src="https://unpkg.com/pinejs-core@1.5.0/dist/pine.min.js" defer></script>

<div p-data="{ count: 0 }">
  <button @click="count++">Increment</button>
  <span p-text="count"></span>
</div>

Upgrade From Alpine.js

Transition existing Alpine.js applications with 0 migration edits via Chameleon Mode, or standardize on p- or prefix-free semantic HTML.

4 Flavor Equivalency (v1.5.0 Larch)

HTML

  <button @click="count++">+1</button>
  <span p-text="count"></span>
</div>

<!-- Flavor 2: Prefix-Free Semantic HTML -->
<div state="{ count: 0 }">
  <button @click="count++">+1</button>
  <span text="count"></span>

<div 🌲="{ count: 0 }">
  <button @click="count++">+1</button>

<!-- Flavor 4: 100% Alpine.js Chameleon Drop-in (Zero edits!) -->
<div x-data="{ count: 0 }">

p-validate

Declarative field and form constraint validation. Automatically injects $errors, $valid, $touched, and $dirty into component scopes with zero boilerplate.

HTML
<div p-data="{ email: '', username: '', age: '' }">
  <!-- Required & Email Format -->
  <input name="user_email" p-model="email" p-validate.required.email />
  <span class="error" p-text="$errors.user_email"></span>

  <!-- Length Constraints -->
  <input name="user_name" p-model="username" p-validate.required.min.4.max.16 />
  <span class="error" p-text="$errors.user_name"></span>

  <button :disabled="!$valid.user_email || !$valid.user_name">Submit Form</button>
</div>

Pine.html()

Compiler-less declarative component template engine. Creates reactive DOM fragments directly from JavaScript template literals with full signal interpolation.

JavaScript

  <div state="{ active: true }" class="card">
    <h3>${title}</h3>
    <button @click="active = !active">Toggle (${count})</button>
    <div show="active">Active Content</div>
  </div>
`;

document.getElementById('app').appendChild(Card({ title: 'Dynamic Widget', count: 10 }));

Pine.worker()

Executes heavy calculations, cryptographic hashing, and data processing in background Web Workers with automatic fine-grained reactive signals.

JavaScript
const worker = Pine.worker((n) => {
  // Runs entirely on background worker thread
  let total = 0;
  for (let i = 0; i < n; i++) total += i;
  return total;
});

// worker.data, worker.loading, and worker.error are reactive signals!
worker.compute(1000000);

Advanced: TypeScript Support & Typings

PineJS ships with first-class TypeScript ambient declaration definitions (dist/pine.d.ts) covering reactive primitives, directives, and magics.

// Strongly-typed Fine-Grained Signals
const count: Signal<number> = signal(0);
const doubled: Computed<number> = computed(() => count.value * 2);

// Reusable typed component factory
Pine.data('userProfile', () => ({
  name: 'Alex',
  age: 28,
  greet(): string {
    return `Hello, ${this.name}!`;

}));
