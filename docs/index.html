Start Here

PineJS is a lightweight, fine-grained declarative micro-framework for building modern reactive web applications directly in your HTML markup.

🌲 Signals + Alpine Ergonomics: Powered by true Fine-Grained Signals with atomic DOM bindings, sub-millisecond execution latency, and < 8 kB footprint.

Quick Example

HTML
<script src="https://unpkg.com/pinejs-core@1.0.0/dist/pine.min.js" defer></script>

<div p-data="{ count: 0 }">
  <button @click="count++">Increment</button>
  <span p-text="count"></span>
</div>

Upgrade From Alpine.js

Transition existing Alpine.js applications in 60 seconds by replacing x- with p-.

Syntax Equivalency

HTML
<!-- Alpine.js: -->
<div x-data="{ open: false }">
  <button @click="open = !open" :class="{ 'active': open }">Toggle</button>
  <span x-show="open" x-text="'Visible!'"></span>
</div>

<!-- PineJS: -->
<div p-data="{ open: false }">
  <button @click="open = !open" :class="{ 'active': open }">Toggle</button>
  <span p-show="open" p-text="'Visible!'"></span>
</div>

Essentials: State

Manage nested objects, arrays, and getters with fine-grained reactivity.

HTML

}">
  <h3 p-text="profile.name"></h3>
  <p p-text="profile.role + ' - ' + status"></p>
  <button @click="toggle">Toggle Status</button>
</div>

p-data

Declares a new component root element and initializes its fine-grained reactive state object.

HTML
<div p-data="{ open: false, items: ['Alpha', 'Beta'] }">
  <button @click="open = !open">Toggle List</button>
  <ul p-show="open">
    <template p-for="item in items"><li p-text="item"></li></template>
  </ul>
</div>
